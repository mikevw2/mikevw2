# Real Feed — AI Video Filter for YouTube & TikTok

A browser extension that finds AI-generated videos in your YouTube and TikTok feeds and **hides**, **blurs**, or **labels** them. It works on Chrome, Edge, Brave, and Firefox. Everything runs locally: no accounts, no servers, no data leaves your browser.

## What it does

| Where | What happens to an AI video |
|---|---|
| YouTube home, search, subscriptions, sidebar, channel pages, Shorts shelf | Removed from the grid |
| YouTube Shorts player | Covered, paused, and **auto-skipped** to the next short |
| TikTok For You / Following | Covered, paused, and **auto-skipped** |
| TikTok profile, search, explore, tag grids | Removed from the grid |
| A video you open directly (`/watch`, TikTok video page) | Warning banner and pause, with *Go back* / *Show anyway* |

Every flagged video says **why** it was flagged. You can override any decision:

- **🤖 Mark AI**: hover any video and click it to block that channel from now on.
- **Not AI · trust @channel**: unblocks a channel for good.
- **Show anyway**: reveals one video and leaves a small 🤖 AI badge on it.

## How it detects AI videos

Each video gets a score from the metadata the feed shows. A video is filtered once its score reaches the threshold for your sensitivity setting (Relaxed 80 · Balanced 50 · Strict 30).

| Signal | Points |
|---|---|
| **Platform disclosure label**: YouTube's *"Altered or synthetic content"*, TikTok's *"AI-generated"* / *"Creator labeled as AI-generated"* | +100 |
| AI-generator hashtags (`#sora`, `#veo3`, `#aivideo`, `#klingai`, `#midjourney`, `#aiart`, …) | +60, +20 more if there are several |
| Creator phrasing (*"made with AI"*, *"AI-generated"*, *"fully AI"*, *"generated by Sora 2"*) | +50 |
| Your own keywords | +50 each |
| Generator named unambiguously (*Sora 2*, *Veo 3*, *Kling AI*, *Runway Gen-4*, …) | +30 |
| `#ai` | +35 |
| Channel named "… AI" or a handle like `@xyz_ai` | +25 |
| Video is *about* AI (review, tutorial, news, "how to spot", "vs") | −30 |
| Creator says *"no AI"*, `#noai`, *"real footage"* | −60 |
| Channel on your block list / trusted list | always / never |

Some care went into avoiding false positives. Bare "Sora" (Kingdom Hearts), "runway" (fashion), "veo" (Spanish), "Pikachu", "Thai", and "Kai" don't count. Fancy Unicode fonts like `𝗮𝗶𝘃𝗶𝗱𝗲𝗼` are normalized, so they can't be used to dodge detection.

### Limitations (please read)

- **It reads labels and metadata, not pixels.** If an uploader doesn't disclose or tag an AI video and the platform doesn't label it, this filter won't catch it. Reliable visual AI detection isn't possible today, even for dedicated services. Use **🤖 Mark AI** on channels it misses; your block list is the strongest signal you have.
- **Platform markup changes.** YouTube and TikTok change their HTML often. The selectors live in `src/platforms/*.js` and are written to fail safely: if one breaks, videos just stop being filtered on that surface. Nothing else breaks.
- Auto-skip clicks the platform's own "next video" control or scrolls to the next item. Turn it off in the popup if you'd rather see the cover card.

## Install

**Chrome / Edge / Brave**
1. Download this folder (`ai-feed-filter/`).
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the `ai-feed-filter` folder.
4. Pin **Real Feed** from the puzzle-piece menu to reach the settings.

**Firefox (121+)**
1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and select `ai-feed-filter/manifest.json`.
   (A permanent install needs the add-on signed through addons.mozilla.org.)

## Settings (toolbar popup)

- On/off switch, plus per-platform toggles
- **When found**: Hide · Blur · Label
- **Sensitivity**: Relaxed · Balanced · Strict
- Auto-skip in Shorts / For You
- Show or hide the "Mark AI" hover button
- Edit the block list, trusted list, and extra keywords
- Running count of filtered videos

Settings sync across your signed-in browsers through `chrome.storage.sync`. The only permission the extension asks for is `storage`.

## Project layout

```
manifest.json            MV3 manifest (Chrome + Firefox)
src/detector.js          Scoring engine: pure logic, no DOM, unit-tested
src/common.js            Default settings and DOM helpers
src/platforms/youtube.js YouTube card selectors and metadata extraction
src/platforms/tiktok.js  TikTok card selectors and metadata extraction
src/content.js           Scanning, hide/blur/label, auto-skip, buttons
src/content.css          Injected styles (all prefixed .aiff-)
popup/                   Settings UI
tests/                   Unit tests + Playwright end-to-end smoke test
```

## Development

```bash
npm test            # detector unit tests (Node 18+, no dependencies)
npm install         # only needed for the end-to-end test
npm run test:e2e    # loads the extension in Chromium against mock YouTube/TikTok pages
npm run zip         # package for the Chrome Web Store
```

To tune detection, edit the rules in `src/detector.js` and add a case to `tests/detector.test.js`. If a platform changes its layout, update the selectors in `src/platforms/`.
