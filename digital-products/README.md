# Digital Spreadsheet Shop

Two tested spreadsheet products and a bundle, ready to sell on Etsy or Gumroad.

- `LAUNCH-PLAN.md`: the 45-minute setup and the 30-day traffic plan. **Start here.**
- `LISTINGS.md`: copy-paste titles, descriptions, tags and prices
- `listing-images/`: 2000×1600 listing images
- `products/QUICK-START.txt`: the buyer guide included in each download
- `build/`: generators for the products and images. This repo is public, so the finished `.xlsx`/`.zip` files are git-ignored. Rebuild them with the commands in LAUNCH-PLAN.md.
