Start with 15 boards, grow to 25 by January. Pin from the approval queue only; 3–5/day during warm-up, 3–10/day after Standard access. Never connect the Shopify catalog app before ~4 clean weeks.

## Pin format rules (enforced in `store-ops`)
- 2:3 ratio, 1000×1500. Real product photo or real room photo in a templated layout; generative images only as backgrounds and only with IPTC AI metadata kept.
- Title ≤100 chars, keyword first. Description 2–3 sentences, natural keywords, no hashtag walls.
- Every pin links to a collection, guide or Etsy listing. Max 1 pin per URL per 7 days; new image every time.
- Mix: ~50% to guides/collections, ~30% to products, ~20% to Etsy listings.
- Auto-pause if weekly impressions drop >50% or any API error.
