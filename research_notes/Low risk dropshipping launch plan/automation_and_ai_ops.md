# Automation and AI Operations for a Small Shopify Dropshipping Store (state as of 2026-10-08)

Scope note: this file maps the recurring tasks of running a small Shopify dropshipping store to (a) off-the-shelf Shopify apps / supplier integrations, (b) Claude-based agent approaches (Claude Code routines, Agent SDK, Managed Agents, Cowork scheduled tasks, MCP connectors), or (c) tasks that must stay with the human. Every capability claim is dated where the source dates it. Research-preview / beta / early-access features are flagged. Most pricing figures come from vendor pages fetched on 2026-10-08 unless noted; several come from third-party guides and are flagged as such.

## Key Question 1: Shopify's developer and AI surface in 2026 (Admin GraphQL, REST status, CLI, Dev MCP, AI Toolkit, official Claude connector, Sidekick, Flow, Magic, agentic commerce)

### Takeaway
By October 2026 an agent can read and write almost everything in a Shopify store through three sanctioned routes: the GraphQL Admin API (REST is "legacy" since Oct 1 2024; new public apps must be GraphQL-only since Apr 1 2025), Shopify's official Claude connector (an MCP server at `setup.shopify.com/mcp`, 25 tools, added April 2026, read+write for products, inventory, discounts, orders, customers, analytics), and the open-source Shopify AI Toolkit plugin for Claude Code that executes store-management tasks through the Shopify CLI's authenticated store context. Shopify's in-admin Sidekick can itself execute multi-step tasks, save repeated prompts as "skills," and build Flow workflows; Flow is free on all plans. Agentic-commerce surfaces (Catalog MCP, Checkout MCP/UCP, Universal Cart) are for buyer-side agents and are partly early-access.

### Cited Findings

**Admin API / REST deprecation**
- "The REST Admin API is a legacy API as of October 1, 2024." "Starting April 1, 2025, all new public apps must be built exclusively with the GraphQL Admin API." "Some newer platform features may only be available in GraphQL." The REST reference page names no removal date; current example version is 2026-10. — [Shopify REST Admin API reference](https://shopify.dev/docs/api/admin-rest)
- Third-party integrator (Zoho) told its users to finish REST-to-GraphQL migration by Sept 1 2026, describing REST as deprecated; this is an integrator notice, not a Shopify announcement. — [Zoho community notice](https://help.zoho.com/portal/vi/community/topic/important-update-shopify-migrating-from-rest-api-to-graphql-api-27-5-2026)
- Shopify: "Starting January 1, 2026, you will not be able to create new legacy custom apps. This will not impact any existing apps." — [Shopify dev community (official post)](https://community.shopify.dev/t/starting-january-1-2026-you-will-not-be-able-to-create-new-legacy-custom-apps-this-will-not-impact-any-existing-apps/26798)
- Admin-created custom apps: "You can no longer create new admin-created custom apps." Existing ones keep working; their token is shown once, cannot be rotated (uninstall/reinstall needed), and "Develop apps" staff permission is required for every scope. New apps go through the Dev Dashboard "with a proper OAuth flow." — [shopify.dev admin app access tokens](https://shopify.dev/apps/auth/admin-app-access-tokens)
- For Dev Dashboard apps on your own store, community guidance: set scopes, release a version, install from the app's Home tab, then POST to `/admin/oauth/access_token` with `grant_type=client_credentials`; a Shopify community reply says these tokens expire after 24 hours and must be re-requested (so an agent needs refresh logic). Conflicting third-party guides (DeployHQ says copy a `shpat_` token; Celigo says Dev Dashboard apps provide no static token in the UI). — [Shopify dev community thread](https://community.shopify.dev/t/unable-to-generate-shopify-oauth-admin-api-access-token/28300/2); [Celigo docs](https://docs.celigo.com/hc/en-us/articles/9251883344667-Set-up-a-token-connection-to-Shopify); [DeployHQ guide](https://www.deployhq.com/support/servers/adding-a-server/shopify/creating-a-custom-shopify-app.md)

**Dev MCP server and Shopify AI Toolkit (developer-facing)**
- Shopify Dev MCP: "The server runs locally and doesn't require authentication." Claude Code install: `claude mcp add --transport stdio shopify-dev-mcp -- npx -y @shopify/dev-mcp@latest`. It is a docs/schema helper, not a store-data server. — [shopify.dev Dev MCP](https://shopify.dev/apps/build/devmcp)
- Shopify AI Toolkit "connects your AI coding tools to Shopify's developer docs, API schemas, and CLI store management"; it can "prepare and run supported store-management tasks through Shopify CLI's authenticated store context, with you choosing when to execute them." Requires Node.js 18+. Install as plugin (recommended, auto-updates) or `npx skills add Shopify/shopify-ai-toolkit` (skills "don't update automatically"). Older per-surface skills (`shopify-admin`, `shopify-admin-execution`, `shopify-liquid`, 20 others) are deprecated and "no longer receive updates"; the current single skill is `shopify`. — [shopify.dev AI Toolkit](https://shopify.dev/docs/apps/build/ai-toolkit); [shopify.dev Dev MCP page](https://shopify.dev/apps/build/devmcp)
- Toolkit GitHub README: Claude Code install is `claude plugin install shopify-ai-toolkit@claude-plugins-official`; "Telemetry is on by default" (opt out via `~/.config/shopify-ai-toolkit/opt-out` or `OPT_OUT_INSTRUMENTATION=true`); on Claude Code "the user's most recent prompt may be sent when a Shopify skill activates." MIT-licensed. — [GitHub Shopify/shopify-ai-toolkit](https://github.com/Shopify/shopify-ai-toolkit)
- Third-party coverage says the toolkit was open-sourced April 9 2026 and warns "there is no rollback on executed store operations," so test on a development store first. — [Learn AI Repeat newsletter](https://learnairepeat.beehiiv.com/p/claude-s-shopify-connector-what-it-actually-does-and-how-to-use-it-in-2026); [tenten.co](https://tenten.co/shopify/shopify-ai-toolkit-what-it-actually-does-how-to-install-it-and-what-matters-for-store-operations/)

**Official Shopify connector for Claude (merchant-facing MCP)**
- Claude connector directory lists "Shopify" (by Shopify, "Anthropic verified," added April 2026, URL `https://setup.shopify.com/mcp`): "Build, manage, and analyze your Shopify store"; can "manage inventory across locations, create discount codes, review orders and customer details" and pull store analytics. 25 tools, including `list-orders`, `get-order`, `list-customers`, `get-inventory-levels`, `create-product`, `update-product`, `set-inventory`, `create-discount`, `bulk-update-product-status`. No fulfillment tool is named on the page. No plan requirement stated. — [claude.com/connectors/shopify](https://claude.com/connectors/shopify)
- Shopify Help Center: you can connect a store to ChatGPT, Claude or Perplexity and "ask questions and manage store data like products, orders, and customers"; "Use the official Shopify app for each AI tool rather than setting up a custom connector"; only one store can be connected at a time; "If an AI tool makes an incorrect change to your store, then you're responsible for that change. Shopify doesn't review or approve actions that connected AI tools take on your behalf." The Claude connector can "build a store from a storefront preview and manage a store that you own." — [Shopify Help: Building and managing your store with third-party AI tools](https://help.shopify.com/en/manual/apps/connecting-ai-tools)
- Shopify's AI-powered tools page: "Connect to ChatGPT, Claude, or Perplexity to ask questions and manage products, orders, and customers. You control what data is shared." — [Shopify Help: AI-powered tools](https://help.shopify.com/en/manual/ai-powered-tools)

**Sidekick, Flow, Magic (in-admin AI)**
- Sidekick "can analyze data, manage orders, edit products, and work with third-party apps"; longer tasks keep running in the background and notify you; it "presents changes for your review before applying them"; "You can save repeated prompts as skills and run them with a shortcut"; Sidekick Pulse surfaces recommendations on the admin Home page. — [Shopify Help: Sidekick](https://help.shopify.com/en/manual/shopify-admin/productivity-tools/sidekick)
- Spring '26 Edition ("Everywhere," Spring 2026): Sidekick app extensions act inside Judge.me, Klaviyo, Loop, Smile (launch partners); Sidekick works from any screen in the mobile app and Apple Watch; Sidekick can generate purchase orders; Flow gained Sidekick-generated test events, a Liquid code editor, version history, ShopifyQL and more Admin API fields, automatic shipping-label purchase rules; "Agents managing stores: Run your store from Claude, ChatGPT, or Perplexity"; Shopify Inbox gained an AI sales assistant; Catalog API image search and product lookup (up to 50 products/request), Sponsored products "developer preview coming soon." — [Shopify Spring '26 Edition](https://www.shopify.com/editions/spring2026)
- Third-party Winter '26 / Spring '26 roundups: Sidekick can "execute tasks instead of just suggesting them," save recurring prompts as repeatable actions, and "build workflows within Shopify Flow simply by describing it"; Shopify reported weekly active Sidekick shops up 4x YoY in Q1 2026 (vendor figure). — [Coalition Technologies](https://coalitiontechnologies.com/blog/shopify-editions-winter-26); [DigitalSuits](https://digitalsuits.co/blog/shopify-spring-2026-edition/)
- Shopify Flow is "a free app that can help you create and run automated workflows in your Shopify admin"; triggers/conditions/actions; third-party guide says free on Basic, Grow, Advanced, Plus, but "Send HTTP request" action needs Grow or higher. — [Shopify Help: Getting started with Flow](https://help.shopify.com/en/manual/shopify-flow/getting-started); [eseospace Flow guide (third-party)](https://eseospace.com/blog/shopify-flow/)
- Shopify Inbox suggested replies: "Shopify Magic generates a suggested reply based on your store information"; on by default; "available only in English." — [Shopify Help: suggested replies](https://help.shopify.com/cs/manual/inbox/chat-settings-and-appearance/shopify-magic)
- Shopify's AI tools page lists built-in generation of product descriptions, blog posts, emails, theme blocks, image background replacement, Inbox instant answers and suggested replies, product category suggestions, and the free "Tinker" mobile app with 100+ AI tools for product photos/videos; "Many of these features are available at no additional cost"; "availability can vary by plan, device, and language." — [Shopify Help: AI-powered tools](https://help.shopify.com/en/manual/ai-powered-tools)

**Agentic commerce (buyer-side agents)**
- shopify.dev agents hub: Global Catalog ("Search products across every Shopify merchant from a single endpoint"), Storefront Catalog (single-merchant scope), Checkout MCP ("Convert carts into checkouts and complete purchases for trusted agents"; higher trust tiers "unlock broader access, including direct checkout completion"), Universal Cart (early access waitlist / "Request access"), AI Toolkit installable as a plugin with a `ucp` skill. — [shopify.dev/docs/agents](https://shopify.dev/docs/agents)
- Third-party (The New Stack, Aug 2025 announcement): Catalog MCP server launched with Catalog, Universal Cart, and Checkout Kit; "Checkout Kit lets partners embed the merchant's checkout in their agent." — [The New Stack](https://thenewstack.io/how-mcp-ui-powers-shopifys-new-commerce-widgets-in-agents/)
- Third-party: the Catalog API no longer requires approval; "Any developer can register an agent profile in the Developer Dashboard and call the public MCP endpoint"; a new "Agentic Plan" lets non-Shopify businesses sync to Shopify Catalog; several agentic features rolled out US-first. — [Taylor Sicard blog](https://taylorsicard.com/blog/shopify-editions-2026-ranked); [Qikify](https://qikify.com/blogs/all-articles/shopify-spring-edition)
- Adoption of Agentic Storefronts was reported as slow, "only about a dozen merchants initially." — [Extuitive (third-party)](https://extuitive.com/articles/shopify-ai-agents-news-march-april)

### Inferences
- For a single owned store, the lowest-friction agent route is the official Shopify connector in Claude (works in claude.ai, Cowork and Claude Code routines as an MCP connector) because it uses Shopify's OAuth and needs no token management; the Admin GraphQL API via a Dev Dashboard app (client-credentials, 24h tokens) is the route for custom Agent SDK code; the AI Toolkit plugin is the route when the owner works in Claude Code and wants CLI-validated execution.
- With an Admin token and the right scopes an agent can create/edit products and prices, adjust inventory, create discounts, read orders/customers, and run analytics; order fulfillment via API (`fulfillmentCreate`) is possible in GraphQL but the official Claude connector does not expose a fulfillment tool, so fulfillment is better left to the supplier app (Key Question 2).
- Shopify itself is pushing merchants toward "agents run your store" (Sidekick skills, Claude/ChatGPT connectors), but all three routes place liability for wrong changes on the merchant, so write actions need guardrails.
- Sidekick's "save repeated prompts as skills" is the native equivalent of a Claude routine but is interactive (shortcut-triggered), not cron-scheduled; no source showed Sidekick scheduling.

### Gaps
- No source confirmed an exact sunset date or API version that removes REST; Shopify's page names none as of 2026-10.
- Shopify's own docs for Dev Dashboard client-credentials tokens were not fetched; the 24-hour expiry comes from a community reply and a connector vendor.
- The Claude connector page does not state which Claude surfaces (Cowork, routines) can use it, nor OAuth scopes; Claude Code docs say any claude.ai connector can be included in a routine, so it is inferred to work.
- Could not find an official "Summer '26" Edition; the latest Edition found is Spring '26 "Everywhere."

## Key Question 2: Order fulfillment automation (DSers, AutoDS, Zendrop, CJ, Printful/Printify) and what still needs manual review

### Takeaway
Auto-forwarding orders to suppliers and syncing tracking back to Shopify is a solved problem via supplier apps: DSers (free Basic; $19.90 Advanced; $49.90 Pro with 14–21-day tracking sync windows and auto price/stock sync), AutoDS (auto-ordering add-on $9.90/mo), Zendrop (Pro $49/mo with "automated fulfillment"), CJ (free plan with automated order processing), Printful/Printify (free tiers). What still fails and needs review: address/payment exceptions, out-of-stock or price-changed SKUs, supplier delays beyond Shopify Protect's 7-day fulfillment window, and multi-supplier orders.

### Cited Findings
- DSers plans (official): Basic Free (3 stores, 3,000 products, 7-day tracking sync, no auto price/stock sync), Advanced $19.90/mo (10 stores, 20,000 products, 14-day tracking sync, auto price & stock sync), Pro $49.90/mo (25 stores, 75,000 products, 21-day tracking sync), Enterprise $499.90/mo; "Bulk order automation" on paid plans; "Auto-Place Orders" linked but plan not stated; 14-day trial; 20% off yearly. — [DSers pricing](https://www.dsers.com/pricing/)
- AutoDS (official pricing page, base plan prices rendered as placeholders): 3-day trial for $0.99; add-ons: "Auto ordering system" $9.90/mo (includes "Automatic Orders Fulfillment" and automatic tracking number update), VA Access $14.97, Product finding hub $14.97, Mentor $39.97; features listed: "Price & stock monitoring," AI product title/description generator, AI Store Builder, "Claude AI chat-to-sell." — [AutoDS pricing](https://www.autods.com/pricing/)
- Zendrop (official support article): Pro $49/mo ($399/yr) includes unlimited orders, "automated fulfillment," custom branding, US products; Plus $79/mo ($549/yr) adds coaching, print on demand, "chargeback management," private listings, trending product finder; usage-based billing tiers by linked products also exist. — [Zendrop support](https://support.zendrop.com/en/articles/9981459-understanding-zendrop-pricing-plans-a-complete-guide)
- Third-party comparisons (treat as approximate): DSers tracking sync described variously as automatic or "manual update"; AutoDS "Auto sync"; Zendrop "Auto sync + branded tracking"; Zendrop US delivery claims range 3–5 days to 5–8 days. — [Earnifyhub comparison](https://www.earnifyhub.com/blog/dropshipping/dsers-vs-autods-vs-zendrop); [ecommerce-platforms DSers vs Zendrop](https://ecommerce-platforms.com/articles/dsers-vs-zendrop)
- CJdropshipping: free plan with sourcing and fulfillment; paid Plus $15.99, Prime $19.99, Advanced $59.99/mo (third-party listing); Shopify integration "allows for automated order processing and real-time inventory updates." — [SoftwareFinder (third-party)](https://softwarefinder.com/ecommerce-software/cjdropshipping); [Channelwill (third-party)](https://channelwill.com/apps/cjdropshipping)
- Printful: free plan limited to basic tools; paid Growth plan ~ $24.99/mo with up to 33% product discounts (third-party). Printify: Free ($0, up to 5 stores), Premium ~ $29/mo with up to 20% off products (third-party). — [Capterra Printful pricing](https://www.capterra.com/p/209769/Printful/pricing/); [printondemandbusiness.com](https://www.printondemandbusiness.com/printful-vs-printify/)
- Shopify Protect requires that you "Fulfill eligible orders within seven days and provide a tracking number from a supported carrier" to keep fraud-chargeback coverage (see KQ5). — [Shopify Protect](https://www.shopify.com/protect)
- Shopify Flow can automate order tagging, low-inventory alerts, hiding/republishing products on inventory level, and (Grow+) send HTTP requests. — [Shopify Help: Flow](https://help.shopify.com/en/manual/shopify-flow/getting-started); [eseospace](https://eseospace.com/blog/shopify-flow/)

### Inferences
- (a) App-level: supplier apps handle the forward (order to supplier) and the return path (tracking to Shopify) without an AI agent. Choose DSers Advanced ($19.90) for AliExpress, AutoDS + $9.90 auto-ordering add-on for multi-supplier, Zendrop Pro ($49) for US-stock fulfillment, Printful/Printify free tiers for POD.
- (b) Agent-level: a daily Claude routine using the Shopify connector (`list-orders`, `get-order`) can flag exceptions: orders unfulfilled >48h, orders without tracking, orders approaching the 7-day Shopify Protect deadline, address-validation failures, and supplier stock/price mismatches (via AutoDS/DSers notifications or by comparing product costs). The agent should report, not fulfill, because the connector has no fulfillment tool and supplier payment is the human's card.
- (c) Human: paying supplier invoices/top-ups, approving supplier switches when a SKU goes out of stock, and resolving orders stuck in "pending payment" or "risk" status.

### Gaps
- AutoDS base plan prices did not render on the official page; third-party sources cite ~$26.90/mo but disagree. Not verified.
- No official statement from DSers on whether "Auto-Place Orders" (auto-pay) is included at a given plan tier.
- No vendor publishes failure rates for auto-fulfillment (what percent of orders need manual intervention); the "what fails" list is inferred from Shopify Protect requirements and app feature gaps.

## Key Question 3: Customer service automation (Gorgias AI Agent, Shopify Inbox, Tidio Lyro, others; custom Claude support agent; refund autonomy policies)

### Takeaway
Shopify-native support AI is free but limited (Inbox suggested replies, English-only, drafted for a human to send). Gorgias AI Agent is the ecommerce standard: $10–$900/mo helpdesk plus $0.90–$1.00 per AI-resolved conversation ($1.50 overage), with Shopify "Actions" (cancel order, edit shipping address) gated by merchant-set conditions and shopper confirmation. Tidio Lyro starts ~$39/mo for 50 AI conversations and claims 67% average resolution (vendor figure; one merchant was at 28%). A custom Claude agent with order-lookup tools is feasible via the Agent SDK or Managed Agents, but no vendor or source documents a safe autonomous refund policy beyond conditions-plus-confirmation; refund caps must be designed by the owner.

### Cited Findings
- Gorgias pricing (official): Starter $10/mo (50 tickets, 30 automated AI interactions), Basic $50/mo annual or $60 monthly (300 tickets, 30 AI interactions), Pro $300/$360 (2,000 tickets, 190 AI interactions), Advanced $750/$900 (5,000 tickets, 530 AI interactions), Enterprise custom; ticket overage $0.36–$0.40; AI Agent "$0.90 on annual contracts, $1.00 on monthly," overage $1.50/interaction; "Each automated interaction also counts as one helpdesk ticket"; Gorgias claims it powers conversations for "40% of Shopify brands"; no platform-wide resolution rate stated; one testimonial (Orthofeet) above 50% automation. A second data block on the same page shows different monthly prices ($77/$471/$1,227), so the page is internally inconsistent. — [Gorgias pricing](https://www.gorgias.com/pricing)
- Third-party (Sept 2026): the pricing page's AI toggle defaults ON, inflating sticker prices; a conversation counts as automated only if no human touches it within 72 hours. — [DragApp Gorgias pricing analysis](https://www.dragapp.com/blog/gorgias-pricing/)
- Gorgias AI Agent Actions (official help center): "connecting Shopify adds actions like Cancel order and Edit shipping address"; "Conditions set the criteria that must be met before an action runs"; customer confirmation "is turned on automatically for irreversible actions, such as canceling an order"; Playground tests "use real data from your connected apps"; available on "All plans with AI Agent"; no refund-amount cap setting mentioned. — [Gorgias Help Center: Allow AI Agent to perform actions](https://helpcenter.gorgias.com/en-US/allow-ai-agent-to-perform-actions-567325)
- Gorgias Recharge actions: cancel subscription escalates to a human if the shopper has several subscriptions; skip shipment only before the order is created. — [Gorgias docs: Recharge actions](https://docs.gorgias.com/en-US/ai-agent-actions-manage-recharge-subscriptions-757839)
- Third-party reviews of Gorgias AI Agent cite a practical ceiling of ~50–60% deflection on repetitive FAQs and say the most repeated criticism is that "it makes things up." — [Macha (competitor blog)](https://www.getmacha.com/blog/gorgias-ai-agent-review)
- Tidio: Starter $29/mo (100 conversations); Lyro AI add-on from ~$39/mo for 50 AI conversations, ~$0.50–$0.70 per conversation at volume; pay-per-resolution only on Premium (custom, from 3,000 AI conversations); Tidio claims "67% average" resolution (up to 89% on homepage), with a 50% "Resolution Rate Guarantee" on Plus/Premium; a Shopify App Store reply (Aug 2025) showed a merchant at 28% with incomplete catalog setup. — [CostBench Tidio pricing](https://costbench.com/guides/tidio-pricing-2026/); [DragApp Tidio pricing](https://www.dragapp.com/blog/tidio-pricing/); [Tidio Shopify reviews](https://apps.shopify.com/reviews/1831268)
- Engaige (vendor) cites MR MARVIS resolving "over 60%" of conversations its agent handles across 120,000 questions/year. — [Engaige blog](https://letsengaige.com/blog/top-ai-agent-support-chatbot-shopify/)
- Shopify Inbox suggested replies are drafted into the merchant's composer (human sends), English only; Spring '26 added an AI sales assistant in Inbox that recommends products to Shop-signed-in customers. — [Shopify Help: suggested replies](https://help.shopify.com/cs/manual/inbox/chat-settings-and-appearance/shopify-magic); [Spring '26 Edition](https://www.shopify.com/editions/spring2026)
- Claude Agent SDK: "Permissions: Control which tools run automatically, which need approval"; hooks "Run custom code at key points in the agent lifecycle"; MCP for external tools; "Anthropic does not allow third party developers to offer claude.ai login or rate limits for their products" (Agent SDK apps must use API keys). — [Claude Agent SDK overview](https://code.claude.com/docs/en/agent-sdk/overview)

### Inferences
- (a) For a store doing under ~300 tickets/month, Gorgias Basic ($50–60) plus AI Agent at ~$1/resolution is the cheapest "real" option; expect realistic autonomous resolution of 30–60% (WISMO, policy questions, address edits), not vendor headline numbers.
- (b) A custom Claude support agent (Agent SDK or Managed Agents + Shopify connector/GraphQL tools for order lookup, plus an email/chat channel) is viable and can be cheaper at low volume (Haiku-class tokens per ticket are cents), but you then own hallucination controls, escalation, and channel plumbing.
- Refund autonomy: no vendor exposes a documented dollar cap; a safe policy modeled on Gorgias' pattern is: auto-approve only when conditions are mechanically checkable (order unfulfilled and < N days old -> cancel/refund; tracking shows delivered-to-wrong-address -> reship) and under a fixed amount (e.g., < $25 or < 1x average order value), require shopper confirmation, and route everything else (chargebacks, INAD/INR claims, high-value orders) to the weekly human review.
- (c) Human: chargeback evidence submission (or Chargeflow), disputes above threshold, legal/privacy requests, and any reply the agent flags as low-confidence.

### Gaps
- Could not retrieve official Zendesk, Richpanel, or Willdesk 2026 pricing; not researched in depth due to call budget.
- No independent (non-vendor) resolution-rate benchmark for Shopify stores was found.
- No documented example of a merchant running a fully autonomous refund policy with an AI agent; the policy above is synthesized.

## Key Question 4: Marketing automation (product copy/images, ad creative, Meta and TikTok APIs, Klaviyo) and verification requirements

### Takeaway
Copy and image generation are free inside Shopify (Sidekick/Magic/Tinker) or trivially done by a Claude routine via the connector. Meta's Marketing API allows a merchant to manage their OWN ad account with default "Limited" (formerly Standard) access and no App Review; Full Access (needed only for other people's accounts) requires App Review, Business Verification, and 500+ API calls/15 days with <15% error rate. TikTok requires registering a developer app, scope review, and Business Center authorization, with approval reported at days to weeks. Meta has no documented API-level account spend cap, so runaway-spend guardrails must be built (campaign `spend_cap`, account spending limit set in Ads Manager, plus an agent that polls Insights and pauses). Meta is enforcing AI-content disclosure in 2026 (third-party reports: ~14% of rejections). Klaviyo is free to 250 profiles/500 sends; paid email from ~$20/mo (third-party).

### Cited Findings
- Meta Marketing API tiers (official): Limited access is "Automatically granted when you add the Marketing API product to your app," "Heavily rate-limited per ad account. For development only," 1 system user; Full access after App Review, "Lightly rate limited per ad account," 10 system users; "Standard Access" renamed Limited, "Advanced Access" renamed Full; threshold dropped from 1,500 to 500 successful calls in 15 days with error rate below 15% over the last 500 calls; "If your app is only managing your ad account, standard access to the ads_read and ads_management permissions are sufficient"; Business Verification required if the app will access sensitive data / advanced access. — [Meta Marketing API authorization](https://developers.facebook.com/docs/marketing-api/overview/authorization)
- Meta Business Verification: "Apps that request advanced access for permissions and apps that allow other Businesses to access their own data must be connected to a Business that has completed Business Verification." — [Meta developers (via search summary)](https://developers.facebook.com/docs/marketing-api/get-started/authorization)
- Meta spend controls: account spending limit is cumulative (doesn't reset monthly) and not available to manual-payment accounts; campaign spending limit is a hard cap with US minimum $100; no official API field for an account-level cap found; a third-party agent skill references campaign `spend_cap` (min 100 in account currency). — [Orbee KB](https://kb.orbee.com/meta-ads-spending-limit); [Jon Loomer](https://www.jonloomer.com/campaign-spending-limits-account-spending-limits-daily-spending-limits/); [gomarble-agent skill (third-party)](https://cdn.jsdelivr.net/npm/gomarble-agent@0.1.2/skills/meta-create-campaign/SKILL.md)

## Key Question 7: Risks of over-automation and recommended human checkpoints

### Takeaway
The documented failure modes are: wrong store edits with no rollback and full merchant liability (Shopify's terms for AI-tool actions), AI support agents that "make things up" (Gorgias reviews; Shopify Inbox drafts can commit you to refunds), ad rejections/strikes for undisclosed AI creative (Meta, 2026), runaway spend because Meta exposes no API-level account cap, and routines whose green status hides task failure. A weekly 30-minute human review plus a small set of hard gates (read-only connectors for monitors, draft-only writes, spend caps set in Ads Manager, refund threshold, Managed Agents dollar budgets) covers these.

### Cited Findings
- "If an AI tool makes an incorrect change to your store, then you're responsible for that change. Shopify doesn't review or approve actions that connected AI tools take on your behalf. Review changes to orders, prices, and inventory carefully, especially when you first start." — [Shopify Help: third-party AI tools](https://help.shopify.com/en/manual/apps/connecting-ai-tools)
- Routines: "Claude can use every tool from an included connector, including writes, without asking for permission during a run"; "A green status in the run list ... does not mean the task in your prompt succeeded." — [Claude Code docs: Routines](https://code.claude.com/docs/en/routines)

- Gorgias AI Agent: most repeated criticism is "it makes things up" (competitor review); Gorgias' own guardrails are conditions + mandatory shopper confirmation for irreversible actions. — [Macha review](https://www.getmacha.com/blog/gorgias-ai-agent-review); [Gorgias Help Center](https://helpcenter.gorgias.com/en-US/allow-ai-agent-to-perform-actions-567325)
- Shopify Magic drafts "for complaints or refund requests can commit you in writing to something you did not intend to offer" (third-party). — [eesel.ai guide](https://www.eesel.ai/blog/shopify-magic-ai-suggested-replies)

- Legally/practically human-only: supplier payments and credit lines, tax registrations and filings sign-off, chargeback evidence on non-fraud disputes, platform policy appeals (Meta/TikTok/Shopify Payments), privacy/data requests, and any public-facing AI content disclosure decisions.
